# Локальная dev-сборка «Династии»

В Community Mods идентификатор служит ключом мода. При совпадении ID локальная копия вытесняет скачанную из списка установленных, а менеджер отмечает конфликт при сверке с каталогом. Скрипт ставит локальные копии со своими ID `com.pa.dynastiya.client.dev` и `com.pa.dynastiya.server.dev`. Постоянные ID сохраняют выбор в Community Mods при обновлении. Коммит каждой части и дата установки видны в её названии. Суффикс `-dirty` означает, что у исходного репозитория были незакоммиченные изменения. [Руководство по локальным модам PA](https://wiki.palobby.com/wiki/Creating_Your_First_Planetary_Annihilation_Mod#Mod_Identifiers)

1. Закрой Planetary Annihilation: TITANS. Для установки нужны Git и Node.js. Скрипт проверен на Node.js 24. Выбери нужную ветку в обоих репозиториях.
2. Из серверного репозитория запусти скрипт в PowerShell.

   ```powershell
   node tools/install-dev.cjs
   ```

   Скрипт ищет клиентский репозиторий рядом с серверным под именем `client` или `pa.dynastiya.client`. Для другого расположения добавь `--client "путь к клиентскому репозиторию"`. Обе части устанавливаются в `client_mods` и `server_mods` внутри `%LOCALAPPDATA%\Uber Entertainment\Planetary Annihilation`. Для отдельного профиля передай его путь в кавычках первым аргументом.
3. Запусти игру. В **Community Mods**, во вкладке **Installed**, выключи опубликованные **Dynastiya Server** и **Dynastiya Client**, если они включены. Включи **Dynastiya Server DEV**. Его зависимость **Dynastiya Client DEV** включается вместе с ним. Проверь обе части во вкладках активных модов и создай локальное лобби. Для загрузки внешних зависимостей из каталога нужен интернет.

Для обновления закрой игру и запусти ту же команду. Для возврата к релизу выключи обе части DEV и включи опубликованный серверный мод. Чтобы удалить dev-сборку, после выхода из игры удали две папки с суффиксом `.dev`, пути к ним выводит установщик.
