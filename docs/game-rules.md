# Правила матча

Основной режим «Династии» — Eradication. Армия проигрывает, когда у неё не остаётся командеров. Для этого дополнительные условия Eradication по вспомогательным командерам, заводам и фабрикаторам выключены; sudden death тоже выключен, поскольку имеет приоритет над Eradication.

Лобби хоста включает эти настройки и ожидает их подтверждения сервером перед запуском. Интерфейс показывает правила всем игрокам и не позволяет изменять их. Поскольку публичный сервер использует стандартные серверные скрипты, эта защита действует в клиентском интерфейсе и не заменяет проверку на сервере.
