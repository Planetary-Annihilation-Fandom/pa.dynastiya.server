# Мгновенные состояния управления

## Политика

Общие состояния normal, hover, pressed, selected, focus и disabled меняют оформление без CSS-перехода. Правило действует и вне hover: иначе уход курсора запускает обратный переход. Подключение через `scenes.global_mod_list` распространяет правило на представления игры, включая дочерние панели; существующие обработчики, фокус, геометрия и `pointer-events` сохраняются.

Реализация находится в клиентском моде, `ui/mods/dynastiya.control_feedback/control_feedback.css`. Установленные файлы игры не изменяются. Открытие панелей отделено от подсветки: у HUD сохранены исходные длительности, но переходы ограничены `right/opacity`, `height/opacity`, `opacity` либо `left` в зависимости от контейнера. Глобального отключения анимаций, tooltip и модальных `.fade` нет.

## Аудит исходников

Первичный инвентарь содержит 97 CSS-блоков с объявлениями переходов в `ui/main`, исключая сторонние библиотеки. Это поиск по тексту, включая объявления `none`, а не число дефектов; [JSON](research/2026-11-09-control-feedback/source-transitions.json) содержит файлы, селекторы и свойства. Bootstrap дополнительно проверен как источник переходов полей: они перекрываются общими селекторами `input`, `select`, `textarea`, `button` и `.btn`.

| Механизм | Решение |
|---|---|
| Общие `.btn_std`, `.btn_hero`, `.btn_neg`, `.btn_std_gray`, `.btn_back`, `.btn_std_ix` | Переходы отключены в обычном состоянии и состояниях ввода; для `.btn_std_ix` также снимается исходная задержка 1 мс |
| Переключатели лобби, `.econ-button`, вкладки и пункты dropdown | Общие правила перекрывают сценовые 300 мс через `!important`; в исходных CSS вне сторонних библиотек конкурирующих `transition: … !important` не найдено |
| Сценовые карточки, кнопки HUD, списки выбора | Найденные классы перечислены явно; покрытие CSS по коду не означает отдельную runtime-проверку каждой сцены |
| Панели команд и приказов HUD | Сохранено движение контейнеров; список анимируемых свойств ограничен отдельно от кнопок внутри |
| Фон главного меню, cinematic, появление/исчезновение боевых уведомлений | Сохранены: не являются задержкой непосредственного состояния контрола |
| `.span_hotkey`, tooltip и всплывающая информация | Не меняются в #5; отдельная задача #6 |

В `new_game.js`, `start.js`, `settings.js` проверены таймеры, debounce/throttle, jQuery-анимации и принудительный сброс фокуса. Общая скриптовая задержка выбора/нажатия не подтверждена. Сохранены сетевые повторы, cooldown, автозапуск, ожидание загрузки, обновление списков настроек и подписка на потерю фокуса окна. В лобби `leave` отправляет сообщение до 30-мс перехода сцены; это не основание удалять ожидание протокола. Подписки и hit testing не переписываются без найденного дефекта.

При подключении уже существует отдельный экран с сообщением о состоянии и отменой; загрузка планет отражается в лобби. Отдельные изменения busy/error генератора вынесены в [#11](https://github.com/Planetary-Annihilation-Fandom/pa.dynastiya.server/issues/11), прототип удалён из клиентской ветки #5. Сохранение настроек и прочие async-операции не объявляются ускоренными этим CSS.

## Проверка характерных примеров

Условия: сборка 124685, игровой Coherent, изолированный host `9881`, 1920×1080, масштаб 1. Использованы исходники и CDP; Computer Use и снимки экрана не применялись. Сравнение: исходный стиль, патч, возврат исходного стиля, повторное включение патча. Между состояниями hover/pressed/уход посылается настоящий ввод через CDP; операция кнопки не выполняется — отпускание происходит вне неё.

| Пример | До | После | Данные |
|---|---|---|---|
| Лобби, `.btn_toggle`, без системы | Уход: 300 мс, сохраняются цвет и тень нажатия | 0 мс, сразу обычные цвет и тень | [Финальный прогон](research/2026-11-09-control-feedback/new-game-new-game-html-1794248956032.json) |
| Лобби, та же механика с системой и готовым предпросмотром | 300 мс | 0 мс | [Прогон с предпросмотром](research/2026-11-09-control-feedback/new-game-new-game-html-1794248236308.json) |
| Главное меню, `.btn_std_ix` | Уход: 300 мс + 1 мс delay | 0 мс, delay 0 мс | [Финальный прогон](research/2026-11-09-control-feedback/game-start--1794248889403.json) |
| Настройки, `.btn_std` | Hover: 300 мс | 0 мс | [Финальный прогон](research/2026-11-09-control-feedback/settings-settings-html-1794248913353.json) |
| Игровое меню, собственный `.div_game_menu_item` | Уход: 300 мс | 0 мс | [Дополнительный прогон](research/2026-11-09-control-feedback/live-game-live-game-menu-html-1794248344441.json) |

Во всех перечисленных финальных прогонах центр контрола проходит `elementFromPoint`: CSS не изменил область попадания. Для скрытых командных панелей в игровом Coherent проверено сохранение `pointer-events: none` и переходов `right, opacity` / `height, opacity`; это проверка стилей, не полный игровой тест команд.

В лобби проверен настоящий Tab после фокусировки поля: фокус перешёл в кнопку dropdown и сохранился, её переход равен 0 мс. [Данные клавиатурной проверки](research/2026-11-09-control-feedback/keyboard-focus.json).

Ограничения: измерены вычисленные стили после доставки ввода, а не физическая задержка до пикселей. Редактор и арсенал отдельно не проверяются; исторический обход ошибки начальной отрисовки `.btn_std_ix` не переносится в отдельный патч. Проверки всего набора игровых команд и всех сцен не заявляются. Данные `svg-scale.json` подтверждают геометрию и disabled, но не успешную доставку каждого клика при масштабе 1.25; их нельзя считать полным тестом ввода при этом масштабе.

## Воспроизведение

После запуска изолированного host и открытия нужной сцены, из корня workspace:

```powershell
node mods/dynastiya/server/docs/ui/research/tools/control-feedback.cjs
node mods/dynastiya/server/docs/ui/research/tools/control-feedback.cjs game/start/ .top-nav-mods
node mods/dynastiya/server/docs/ui/research/tools/control-feedback.cjs settings/settings.html .btn_std
```

Инструмент хранит одно подключение на сравнение, сохраняет JSON и восстанавливает включённый патч после прогона. Не запускай его на скрытой панели; проверка координат отвергает элементы вне представления. `source-transitions.json` воспроизводится через `audit-control-transitions.cjs`.

Ранний прогон `settings-settings-html-1794248358840.json` выполнен на скрытой панели 16×16 и не считается проверкой ввода. Ранний `game-start--1794248397690.json` относится к отклонённому варианту с переходом 1 мс у всех `.btn_std_ix`; итоговое правило имеет 0 мс. Эти отрицательные опыты сохранены, чтобы не выдавать их за финальную проверку.
