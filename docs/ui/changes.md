# Журнал оптимизаций интерфейса

## Внедрённые оптимизации

2026-11-09: по решению пользователя убраны все CSS transitions и jQuery-эффекты; известные появления/исчезновения завершаются за 1 мс, время чтения сообщений сохранено. Заставка и завершение видео больше не ждут animationend. Проверены конечная геометрия/ввод в Coherent и ветви модели первого запуска/видео. [Область и ограничения](instant-motion.md). Выигрыш CPU/GPU отдельно не измерялся.

2026-11-09: #7, клиентский коммит `137a132` в `main`: общий `working.svg` заменён статическими песочными часами, вращение всех `img.working` отключено через `global_mod_list`. В лобби без системы p95 rAF 69–77 → 35–38 мс; подключение ресурса и CSS подтверждено после перезапуска профиля. С готовым предпросмотром скрытые индикаторы выигрыша не дали; пульсация тени генератора сохранена после отрицательного опыта. [Аудит остальных эффектов, данные и ограничения](animation-rendering.md). Статус: внедрено; полный ручной обход сцен не выполнялся.

2026-11-09: #6, общий tooltip lifecycle, клиентский коммит `bf0f8ce` влит напрямую в `main` и отправлен в origin. Подключён через `global_mod_list`: hide 100 → 0 мс, animation=false, очистка KO и раздельные hover/focus. Проверены лобби без системы и с Disparity/holodeck, главное меню и тестовый binding настроек; detach примерно 254 → 0,5–1,3 мс. [Методика, данные и исключения](tooltip-lifecycle.md). Статус: внедрено; полный обход всех сцен не заявляется.

2026-11-09 общие мгновенные состояния контролов (#5) влиты напрямую в `main` клиентского репозитория, коммит `1844b6c`. Проверены лобби, главное меню и настройки; подробности и ограничения — в [отчёте](control-feedback.md). Работоспособность окрашивания SVG сама по себе не является доказанной оптимизацией задержки.
