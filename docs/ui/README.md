# Оптимизация игрового интерфейса

«Династия» перерабатывает игру целиком. Правила и план распространяются на весь доступный моду HTML/CSS/JS PA: главное меню, браузер игр, лобби, редактор систем, загрузочные экраны, игровой HUD, панели строительства и выбора, чат, настройки, Galactic War и результаты матча. Они не ограничены уже интегрированными компонентами «Династии».

Основная цель: состояние под курсором и результат действия должны своевременно отражаться на экране, а обновление UI должно быть равномерным. Внешний вид и уменьшение расхода ресурсов оцениваются вместе с задержкой реакции.

Изменять можно общие стили, разметку и скрипты игры через клиентский мод, включая замену исходных компонентов. Для общей политики используй общий модуль, загружаемый до инициализации компонентов во всех нужных сценах, либо точечные переопределения исходных файлов; порядок загрузки и полноту покрытия нужно проверять. Серверные данные и протокол меняются там, где они действительно вызывают лишние обновления UI. Закрытые нативные вызовы Coherent и порядок композиции движка средствами обычного HTML/CSS-мода напрямую не управляются.

## Правила реализации

Начальный участок проверки: меню лобби без системы, затем с системой и предпросмотром. Сначала применяй обоснованные общие изменения CSS/разметки, затем профилируй и переделывай оставшиеся тяжёлые скрипты. Порядок не запрещает проверить найденную причину сразу; отдельная разработка дизайн-системы в эти задачи не входит. Общие замены анимаций и свойств для всех компонентов допускаются с учётом [справочника](optimization-reference.md#как-вводить-общие-переопределения).

Вход в состояние наведения, нажатие, выбор и фокус должны давать немедленную обратную связь. Декоративные переходы открытия и закрытия панелей определяются отдельно; задержку действия нельзя маскировать анимацией. Длительная операция немедленно показывает ожидание, затем завершение или ошибку; подтверждение серверного результата не подменяется ложным успехом.

Геометрия области нажатия должна соответствовать видимому элементу, включая масштаб UI, вложенные SVG и перекрывающие панели. Фокус клавиатуры и управление мышью сохраняются при изменениях.

Стоимость эффектов проверяется в игре. Нет общего запрета на SVG, градиенты, тени или CSS-анимации: в первичной диагностике замена вращающегося SVG на PNG проблему не устранила. Отдельное наблюдение нельзя объявлять ограничением всех SVG или всех сцен.

Для кода внутри проверенного старого Coherent используй совместимый синтаксис и проверяй поддержку CSS/API в игре. Современный браузерный предпросмотр не заменяет проверку игрового рендерера.

При завершении задачи обновляй журнал и ссылки на изменения; измерение, план и прототип не помечай как внедрённую оптимизацию. Состояние исполнения ведётся в задачах, документы содержат правила, результаты и основания решений.
