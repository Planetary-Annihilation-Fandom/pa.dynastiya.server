# Мгновенные переходы интерфейса

Клиентский коммит `1d5dee5`, релиз `0.1.4` в main. Подключение новых модулей полного запуска требует следующего запуска клиента; проверка Coherent ниже выполнена инъекцией в уже открытое изолированное лобби.

По решению пользователя от 2026-11-09 движение и плавная смена состояний UI больше не сохраняются ради оформления. Общий мод отключает все CSS transitions, включая псевдоэлементы, а jQuery.fx.off завершает jQuery-эффекты без промежуточных кадров. В HUD это убирает выдвижение команд и приказов, изменение высоты строк с задержкой, движение подменю и появление панели экономики. Правило действует во всех сценах, загружающих global_mod_list.

Известные CSS-анимации появления/исчезновения (fadein, window_appear, uifadein, семейство label*, containerdisappear, combatappear, deathalert, closedeathalert) завершаются за 1 мс через animationstart, сохраняя конечные стили и lifecycle. Время до закрытия предупреждения о поражении игрока сохраняется; сообщение Bounty показывается без fade на прежний срок. Движущаяся надпись под кнопкой начала матча скрыта. Бесконечные пульсации и боевые вспышки не изменены.

## Заставка и видео

Мод сцены main заменяет model.hideSplash и model.finishVideo: продолжение выполняется напрямую, без ожидания fadeIn/fadeOut и без искусственного animationend. Готовность сцены/модов остаётся условием скрытия заставки. Сохраняются однократность hideSplash, интро при первом запуске, отметка просмотра, очистка видеоплеера, музыка и исходный showGame с сообщением video_complete.

## Проверка и ограничения

В действующем Coherent изолированного host проверен один характерный элемент: высота 0 ↔ 36 px, opacity и pointer-events меняются сразу, transition duration/delay равны 0. Исходная двухсекундная labelopen завершается за 0,001 с, достигает конечного max-width и посылает animationend. [Данные](research/instant-motion-check.json).

Проверка модели без движка покрывает dev-режим, просмотренное интро, первый запуск, завершение GW-видео и повторные вызовы. Она подтверждает прямое продолжение без animationend/таймеров, но не заменяет просмотр роликов. [Данные](research/instant-scene-check.json). Полный обход сцен и новые серии rAF не проводились; величина выигрыша CPU/GPU не измерена.

Неизвестные анимации сторонних модов, нативные анимации игры и отдельные JS-таймеры не объявляются отключёнными. Несколько animation tracks на одном элементе не ускоряются общим обработчиком, чтобы не менять посторонний эффект.
