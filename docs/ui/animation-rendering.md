# Индикаторы ожидания и анимации UI

Последующее решение 2026-11-09: [CSS-переходы и известные появления/исчезновения сделаны мгновенными](instant-motion.md); перечень сохранённых конечных эффектов ниже описывает исходное внедрение #7.

В задаче #7 общий вращающийся `img.working` заменён статическими песочными часами, клиентский коммит `137a132` в `main`. Клиентский мод подменяет `ui/main/shared/img/working.svg` и подключает `dynastiya.animation/animation.css` через `global_mod_list`; вращение остановлено и у видимых, и у скрытых экземпляров. Существующие размеры, KO-видимость, текст состояния и подсказки сохранены. SVG нарисован для «Династии», внешние изображения не использованы.

## Подтверждённый эффект

Проверка 2026-11-09: PA TITANS 124685, Coherent, видимый изолированный host на 9881, 1920×1080, devicePixelRatio=1. В лобби без системы виден один индикатор; сравнивались исходный вариант, остановка исходного изображения, песочные часы и возврат исходного вращения. Мышь перемещалась между двумя одинаковыми точками, соединение CDP сохранялось в пределах прогона. Каждый вариант измерялся около 8 секунд после 1,5 секунды прогрева.

| Вариант | p95 rAF, мс | Доля интервалов >50 мс |
|---|---:|---:|
| Исходное вращение | 69,0 | 13,2% |
| Исходное изображение без вращения | 35,1 | 1,0% |
| Песочные часы | 35,2 | 1,8% |
| Возврат вращения | 77,1 | 15,1% |
| Повтор песочных часов | 34,5 | 1,1% |
| Подключённый мод после перезапуска профиля | 37,6 | 1,4% |

Результат подтверждает пользу остановки непрерывного вращения; сам выбор SVG вместо PNG не объявляется оптимизацией. В лобби с Disparity и готовым предпросмотром все индикаторы скрыты: p95 около 23–24 мс при обоих вариантах. Здесь отдельного выигрыша от замены не обнаружено.

Это равномерность вызовов rAF, а не частота вывода текстуры UI или монитора. Сохранены также интервалы фактического выполнения callback и исходные временные отметки: Coherent может вызывать rAF чаще одного раза за период монитора. Фоновая нагрузка менялась; в ранних сериях были более длинные паузы, поэтому они сохранены отдельно и не смешаны с итоговой таблицей.

## Где используется тот же эффект

Поиск по исходному `media/ui` обнаружил одну реализацию непрерывного вращения, `loading_rotation` в `shared/css/global.css`, и 29 ссылок на `working.svg` в HTML/JS. Общая замена охватывает обычное и рейтинговое лобби, подключение, построение планет, загрузку повторов, главное меню, менеджер модов, Galactic War, статистику, leaderboard, редактор, арсенал и popup паузы HUD. Список ссылок сохранён в [инвентаре](research/2026-11-09/animation-indicator-uses.txt); наличие ссылки не означает отдельную ручную проверку каждого экрана.

Поиск также охватывал CSS/JS-повороты, jQuery `.animate` и SVG `<animate>` вне сторонних библиотек. Других реализаций такого вращения и встроенных SVG-анимаций не найдено; примеры `.animate` в API панелей/holodeck закомментированы.

| Эффект | Что меняется | Решение и основание |
|---|---|---|
| `loading_rotation`, все `img.working` | transform rotate, период 0,7 с | Заменён статической индикацией; улучшение воспроизведено |
| `pulsate`, кнопка генерации «Династии» | drop-shadow радиусом 3–10 px, цвет | Сохранён: отдельная остановка со статической тенью дала p95 24,5–24,8 мс против 23,7–24,4 мс исходного эффекта; пользы нет |
| `header_scroll`, `.title_watermark` | left, opacity; крупный текст с тенью | Сохранён как кандидат для измерения при появлении: соответствующих узлов в проверенных меню, настройках и лобби не найдено |
| `slide_to_right_1/2`, `#logo_slide_top/bottom` | left, opacity | Сохранён: определения есть в CSS start, узлы в проверенном главном меню отсутствуют |
| `community_mods_pulse` | color и background-color | Сохранён: в проверенном offline-меню не активен |
| `commander-pulse`, matchmaking | opacity | Сохранён; другую стоимость рендеринга по названию анимации не предполагаем |
| `pause_glow`, HUD; `loading_pulse`, итог матча | opacity | Сохранены как индикация состояния, аналогичное замедление не установлено |
| Краткие появления панелей, боевые вспышки, уведомления | opacity, геометрия, цвет и тени | Сохранены; конечные эффекты не отключаются вместе с индикатором ожидания |
| Bootstrap progress stripes | background-position | Сохранён, активного экземпляра в проверенных сценах нет |

Общие прозрачные фоны, тени и остальные SVG не менялись. В снимках меню и настроек активных CSS-анимаций не найдено; лобби содержит пульсацию генератора и скрытые исходные индикаторы. Прямоугольники DOM в снимках показывают размеры элементов, но не повреждённые области paint. Попытка Timeline через старый CDP привела к тайм-ауту ввода; эту серию исключили. Разделение стоимости на layout, paint и нативную композицию остаётся неподтверждённым.

## Данные и повторение

Итоговая таблица: [исходный/патч/возврат](research/2026-11-09/animation-empty-final.json), [подключённый мод](research/2026-11-09/animation-integrated-empty.json), [подтверждение ресурса и CSS](research/2026-11-09/animation-integrated-lobby.json). Контроль с предпросмотром: `animation-system-preview.json`; опыт с тенью: `animation-pulse.json`; исходные определения: `animation-source-inventory.txt`, `animation-related-inventory.txt`. Ранние серии `animation-empty.json` и `animation-empty-repeat.json` показывают нестабильность фоновой нагрузки и не являются дополнительными условиями приёмки.

После запуска host и открытия нужной сцены из корня workspace:

```powershell
node mods/dynastiya/server/docs/ui/research/tools/animation-comparison.cjs new_game/new_game.html comparison 8000
```

Инструмент временно возвращает исходные SVG и вращение даже при подключённом патче, затем восстанавливает ресурсы сцены. `--integrated` измеряет только установленный вариант; `--pulse` сравнивает пульсацию кнопки генерации со статической тенью. Не запускать одновременно с другим отладчиком этой сцены. Для обычной правки достаточно характерного сравнения и проверки подключения: полный обход UI и новые серии без конкретного сомнения не требуются.
