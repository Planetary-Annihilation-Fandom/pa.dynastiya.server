# Инструменты первичной диагностики

Из корня workspace `pa`, после запуска видимого host с открытым генератором:

```powershell
node mods/dynastiya/server/docs/ui/research/tools/measure-latency.cjs
node mods/dynastiya/server/docs/ui/research/tools/tooltip-timing.cjs
```

`measure-latency.cjs` принимает последовательность режимов, например `baseline no-spinner baseline-restored`. Список режимов находится в объекте `rules`; каждый режим подаёт 30 движений с паузой 150 мс и переподключением CDP, поэтому фактическая длительность прогонов различается. Это архивируемый инструмент первичной диагностики, не готовый стенд одинаковых по длительности сравнений.

Новые JSON записываются в `../runs/`; данные исходного исследования находятся в `../2026-11-09/`. При другом размещении workspace задай `PA_WORKSPACE`, при другом порте `PA_UI_PORT`. Нужны Node.js с `fetch`/`WebSocket` и существующий `docs/En/Modding/Debug/cdp.js` workspace PA. Не указывай порт основного профиля игрока.

Скрипты временно меняют CSS и двигают указатель в тестовой сцене. Завершай сравнение `baseline-restored`; при аварийном прерывании перезагрузи тестовую сцену для удаления временных стилей. Во время замера не перемещай курсор вручную. `latency-probe.js` выполняется внутри Coherent и не подключается к runtime мода.
