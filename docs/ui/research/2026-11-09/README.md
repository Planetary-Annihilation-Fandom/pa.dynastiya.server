# Условия исходных прогонов

Все прогоны выполнены в видимом тестовом лобби без выбранной системы и без активного предпросмотра. Каждый режим содержит 30 CDP-движений с паузой 150 мс; фактическое время различается из-за отладочного протокола. Количество событий может быть больше при дополнительном движении указателя.

| Файл | Дополнительные условия |
|---|---|
| `latency-results.json` | Первое сравнение baseline/no-motion/возврат |
| `latency-results-1794242783832.json` | Исходный UI; отдельное отключение пульсации и переходов |
| `latency-results-1794242814398.json` | Повторное чередование no-motion и исходного UI |
| `latency-results-1794242847659.json` | Отдельное отключение всех анимаций и вращения индикаторов |
| `latency-results-1794242899666.json` | Отдельное отключение видимого и скрытых индикаторов |
| `latency-results-1794242933966.json` | В обоих режимах активны экспериментальные keyframes вращения с translateZ(0), backface-visibility и will-change |
| `latency-results-1794242968061.json` | В обоих режимах SVG индикатора заменён растровым PNG data URI, вращение сохранено |
| `latency-results-1794242995517.json` | В обоих режимах исходный SVG вращается steps(12,end) с периодом 1,2 с |
| `tooltip-timing.json` | Три наведения на кнопку генератора и ухода; вращение возвращено к исходному виду |

`baseline` и `baseline-restored` в последних трёх файлах означают отсутствие стилей переключения основного измерительного скрипта, но не отсутствие указанного внешнего эксперимента. Их нельзя смешивать с исходным baseline из первых файлов. Эти дополнительные эксперименты улучшения не подтвердили.

`frames` содержит интервалы rAF в миллисекундах, `eventToRaf` начинается в JS-обработчике mousemove. Статистики не являются измерением полной задержки ввода до монитора. Разбор ограничений и выводы находятся в [отчёте](../2026-11-09-responsiveness.md).
