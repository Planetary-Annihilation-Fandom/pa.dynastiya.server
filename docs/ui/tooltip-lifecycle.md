# Общие подсказки: сроки и очистка

Изменение #6 реализовано в клиентском модуле `dynastiya.tooltip`, коммит `bf0f8ce`. Модуль подключён через `global_mod_list` и оборачивает исходный `ko.bindingHandlers.tooltip`, сохраняя локализацию, горячие клавиши, HTML, placement и container. Политика: show=0, hide=0, animation=false; переход на соседний элемент не требует прогрева или отдельной задержки.

## Причина задержки

В исходном `ui/main/shared/js/ko_bindings.js` установлены show=0, hide=100 и animation='fadeIn'. Bootstrap 3.0.3 трактует строку animation как true, добавляет `.fade` и откладывает detach на fallback 150 мс, хотя общий CSS уже выключает видимый fade. Патч убирает оба ожидания; изменение не является ускорением рендерера или доказательством роста FPS. Глобальные `.fade`, модальные окна и прототипы Bootstrap не изменены.

Bootstrap 3.0.3 не объединяет hover и focus: уход мыши может скрыть подсказку фокусированного элемента. Модуль хранит оба состояния отдельно. KO disposal отменяет таймер, уничтожает экземпляр и удаляет его подсказку, включая container=body. Потеря фокуса окна скрывает подсказки; pagehide/unload освобождает зарегистрированные экземпляры. Удаление владельца через KO обязательно для динамической разметки; произвольное удаление нативным DOM API не получает KO disposal автоматически.

## Проверка 2026-11-09

PA TITANS 124685, Coherent Chromium 40, Windows, видимый изолированный host на 9881, 1920×1080, devicePixelRatio=1. Использован настоящий Bootstrap и KO в сценах игры; сравнивались программно доставленные события тестовых кнопок с обычным и body-контейнером. Это сроки JS/DOM, не физическое движение мыши → пиксели. Контрольные прогоны выполнены в порядке исходный → патч → возврат исходного, затем после подключения модуля через профиль.

| Вариант/сцена | Вход → shown, мс | Выход → hide, мс | Выход → detach, мс |
|---|---:|---:|---:|
| Исходный, лобби без системы | 4,76 | 101,12 | 254,29 |
| Патч в той же сцене | 1,90 | 0,18 | 0,59 |
| Возврат исходного | 4,49 | 102,38 | 256,65 |
| Подключённый модуль, лобби без системы | 1,87 | 0,15 | 0,62 |
| Лобби Disparity, 1 планета, holodeck | 1,67 | 0,13 | 0,45 |
| Главное меню | 6,72 | 0,50 | 1,26 |
| Настройки, тестовый binding | 4,84 | 0,31 | 0,85 |

В финальных прогонах: после 40 переходов нет `.tooltip.in`, focus переживает mouseleave, blur скрывает подсказку, новый показ читает обновлённый observable, удаление владельца убирает body-tooltip. Начальная проверка focus через jQuery `.trigger('focus')` зависела от доставки нативного фокуса в Coherent; финальные проверки вызывают `.triggerHandler('focus')` и проверяют обработчик, а не реальный Tab. Снимок focus исходного варианта сделан до истечения его 100 мс и не доказывает удержание после таймера.

В лобби с системой дополнительно проверена исходная `button.option`: animation=false, оба delay=0, показ и синхронное удаление при уходе. В настройках собственных tooltip-bindings не найдено, поэтому там подтверждены загрузка модуля и работа тестового binding. Отдельный полный тест игровых команд, редактора и арсенала не проводился.

## Исключения и воспроизведение

Аудит исходных JS `ui/main` обнаружил один инициализатор Bootstrap tooltip — общий KO binding; другие вызовы в new_game и live_game_action_bar управляют уже созданными экземплярами. Инициализаторов Bootstrap popover вне библиотеки не найдено. Собственные панели HUD, включая `live_game_build_hover` и celestial hover, не являются Bootstrap tooltip и сохраняют свой жизненный цикл; их задержки здесь не оптимизированы. Интерактивные popover сторонних модов также не перехватываются.

Данные: `research/tooltip-before-after.json`, `tooltip-baseline-restored.json`, `tooltip-integrated-*.json`, `tooltip-scene-checks.json`. В массивах событий сохранён первый полный цикл; результаты массовых переходов записаны отдельными полями. Прямой вызов обработчика pagehide удалил открытую body-подсказку и её экземпляр. Отсутствие старых узлов после реальной смены всех игровых сцен и физический клавиатурный ввод отдельно не измерялись.

## Как повторить проверку

После запуска host и открытия лобби, из корня workspace:

```powershell
node mods/dynastiya/server/docs/ui/research/tools/tooltip-lifecycle.cjs new_game/new_game.html result.json
```

Инструмент проверяет подключённый модуль; в сцене без модуля сначала измеряет исходный binding, затем инъецирует патч как прототип. Такие инъекции сами по себе не подтверждают интеграцию.
