# Статичные состояния без CSS-свечения

Изменение #15 подключено в клиенте через `global_mod_list`: модуль `dynastiya.flat_effects` удаляет `box-shadow` и `text-shadow` у элементов и псевдоэлементов, включая hover/focus. Правила с исходным `!important` перекрыты отдельно с сохранением специфичности. Свечение `drop-shadow` удаляется из фильтра, остальные операции сохраняются.

Бесконечные эффекты ожидания, matchmaking, community mods, паузы, загрузки ранга, полос прогресса и декоративные движущиеся логотипы остановлены. Мигающие игровые сообщения и уведомления чата обозначаются статично. Красные, зелёные и другие предупреждения сохраняют цвет; сообщение и его время жизни не удаляются. Радиальные фоновые свечения заменены статичным цветом, пустые слои `.background_glow` скрыты. Клавиатурный фокус обозначен контуром, выбор — цветом рамки, недоступные элементы — прозрачностью.

## Подключение и обновление

Общие тени отключает `global.css`; остальные поправки подключаются только при наличии соответствующего исходного CSS в сцене. Состав `bundle://boot/boot.css` учитывается по `ui/boot.json`. Генератор сохраняет условия `@media` и не переписывает keyframes конечных анимаций.

После изменения исходного UI выполнить из клиентского репозитория `node tools/build-flat-effects.cjs [путь-к-media/ui]`. Генератор обновляет CSS и `inventory.json`; ручные общие правила находятся в `ui/mods/dynastiya.flat_effects/global.css`.

## Проверка

PA TITANS 124685, изолированные профили, Coherent. В главном меню подтверждена штатная загрузка непустых таблиц стилей; у видимых элементов не осталось CSS-теней и `drop-shadow`. В лобби сравнение 37 видимых контролов до/после не обнаружило изменения координат, размеров и `border-image-source`. Снимок окна получен PowerShell через `PrintWindow`, без Computer Use; текст меню читается, исходное растровое оформление сохранено. Полный обход HUD, редактора и арсенала не выполнялся; правила HUD проверяются как общий механизм и по исходным селекторам.

Повторить проверку открытых свободных сцен можно из корня workspace: `node mods/dynastiya/server/docs/ui/research/tools/flat-effects-check.cjs 9881`. Инструмент временно применяет актуальный CSS, сравнивает геометрию и PNG-рамки, проверяет тени элементов/псевдоэлементов и восстанавливает установленный CSS; навигации нет.

При запуске обнаружено, что флаг enabled в Community Mods Manager не гарантирует монтирование файлового мода. В тестовом профиле теперь создаются `client_mods/mods.json`, `server_mods/mods.json` и локальный bootstrap с актуальным списком сцен. Скрипт запуска проверяет сами таблицы стилей. Изолированный bootstrap сохраняет offline-флаг, который исходный startup игры удаляет; обычный профиль игрока и файлы установленной игры не меняются.

Мерцание меню при одновременно открытых полноэкранных host и guest исчезло после закрытия guest; результат подтверждён пользователем. Для обычной проверки запускается один клиент, одновременный запуск требует `--allow-multiple`.

## Оставшееся оформление в ресурсах

PNG-кнопки `shared/img/buttons/`, вкладки `shared/img/tabs/`, рамки `shared/img/panel/`, HUD-фоны `live_game/img/{status_bar,command_bar,build_bar,alerts}/` и `dynastiya.lobby_preview/panel_{std,secondary}.png` сохранены. Тени и мягкие края, нарисованные внутри этих изображений, CSS-правила не удаляют. Их массовая замена однотонным `border-image` нарушила внешний вид и была полностью отменена по замечанию пользователя; следующая обработка ресурсов должна сохранить размеры, форму и исходные срезы рамок.

Иллюстрации главного меню, изображения командиров, значки ресурсов и встроенное художественное освещение не перерабатывались. Полное отсутствие свечения внутри всех растровых изображений не заявляется. SVG-фильтров размытия/свечения в проверенном исходном `media/ui/main` не обнаружено.
