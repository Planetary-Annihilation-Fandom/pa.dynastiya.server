# Классы командеров

Справочник `pa/dynastiya/commander_classes.json` задаёт классы, суперформы и явное соответствие командерам. Клиент читает тот же файл через `spec://`; неизвестные записи не получают класс. Доступность и принадлежность командера игроку по-прежнему определяет игра.

Правила перехода и доступности описаны в [суперформах командеров](superforms.md). Поле `superform` пока используется выбором командера в лобби, а `combatSuperforms` перечисляет строящиеся боевые суперформы класса.

Классовые основы наследуют базовые спецификации соответствующих фракций. Основы Exiles используют `/pa/units/exiles_base/base_exiles_commander.json` из зависимости. Blueberry относится к Raptor, Brainiac к Quad, Maxim к Imperial, Taurus к Tank; их фракционные свойства остаются в исходных спецификациях. Сами основы пока не меняют характеристики командеров.

Для включения классов переопределены четыре базовые спецификации игры и девять файлов Faction Compatibility Mod. При обновлении игры или зависимости проверь исходные файлы и перенеси изменения в соответствующие переопределения, сохраняя путь к классовой основе. Контрольные суммы зафиксированы в `tools/commander-class-sources.json`:

```powershell
node tools/check-commander-classes.cjs "<каталог media игры>" "<каталог Faction Compatibility Mod>" "<каталог Exiles>"
```

После проверки обнови контрольные суммы для рассмотренных исходных файлов. При появлении командеров добавь только проверенные соответствия в справочник; новый выбор не должен включать неизвестные записи.
