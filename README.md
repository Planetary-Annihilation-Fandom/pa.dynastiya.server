# Dynastiya

Dynastiya brings Legion Expansion, Exiles Faction, and Second Wave Expansion together in Planetary Annihilation: TITANS. Enable Dynastiya Server in Community Mods to activate the required mods and [Dynastiya Client](https://github.com/Planetary-Annihilation-Fandom/pa.dynastiya.client).

Commander classes and superforms are based on PA Legends by denst.

[Install a development build](docs/install-dev.md).
