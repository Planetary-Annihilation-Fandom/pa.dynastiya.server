# Версионирование

Общие правила оптимизации всего игрового интерфейса находятся в [docs/ui](docs/ui/README.md). При изменении поведения UI обновляй журнал [docs/ui/changes.md](docs/ui/changes.md), отделяя прототипы и измерения от внедрённых оптимизаций.

При работе над оптимизацией пополняй [справочник](docs/ui/optimization-reference.md): источник гипотезы, способ обнаружения, результат и исключения. Работай в ветке из issue; зависимости из строки «Нужно до начала работ» должны быть влиты в `main` соответствующего репозитория, закрытия issue для этого недостаточно.

Версии клиентской и серверной частей ведутся независимо в их `modinfo.json` по схеме `x.y.z`: `x` повышается при существенном нарушении совместимости, `y` — при необходимости миграции сохранённых данных, `z` — при остальных изменениях. Версию изменённой части повышай в коммите релиза, а не в рабочих ветках; прямое указание пользователя повысить её сейчас имеет приоритет.
